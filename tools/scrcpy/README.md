# scrcpy runtime goes here

Download the complete official Windows x64 scrcpy bundle from [scrcpy releases](https://github.com/Genymobile/scrcpy/releases). Version 4.1 is the tested engine for this source snapshot.

Extract the archive's inner contents here so `scrcpy.exe`, `adb.exe`, `scrcpy-server`, supporting DLLs and notices are directly in this directory. Do not nest an extra release folder. Downloaded files are ignored by Git.

See [build instructions](../../docs/BUILD.md). Keep the engine's notices when distributing a portable app.
