# Optional gaming controller goes here

Build `control-overlay-src/GamingControlOverlay.spec`, then place `GamingControlOverlay.exe` here. Copy the sanitized `control-overlay-src/profiles.example.json` here as `profiles.json` on first setup. Do not replace a saved profile you want to keep.

The app targets `ClearMirror Preview` and applies a saved profile. Adjust positions for your game's HUD. The starter example uses Ctrl for mouse look and F12 for editing.

Binaries and local profiles are ignored by Git. See [the build guide](../../docs/BUILD.md) and [overlay guide](../../control-overlay-src/README.md).
